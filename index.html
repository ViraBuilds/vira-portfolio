About

My story

I'm Vira, an AI-assisted builder. I use AI tools to design and write code — and I check and test what they produce before I ship it.

My work so far is simple on purpose: I find small businesses with no website or a weak one — a barber, a salon, a plumber — and build them a one-page demo site as a free preview, so the owner can see it live before deciding anything.

I also build small tools I need myself. When my videos needed music and I didn't want to use anyone else's copyrighted tracks, I wrote a Python script that synthesises upbeat chiptune loops from scratch — chords, melody, bass and drums, all from sine and triangle waves.

I'm still learning, still building, and still honest about where things stand: what works, works — and what's a work in progress, I say so.
